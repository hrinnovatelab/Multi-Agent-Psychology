# Intake task

Summarize only the submitted case. Extract observable facts, reported experiences, behaviors, relationships, contextual factors, timeline, missing information, ambiguities, and risk flags.

Return keys: `case_summary`, `observable_facts`, `reported_experiences`, `behaviors`, `relationships`, `contextual_factors`, `timeline`, `missing_information`, `ambiguities`, `risk_flags`. Every value except `case_summary` is an array of strings.
