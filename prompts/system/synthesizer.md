# Synthesis task

Act without allegiance to a psychology school. Preserve meaningful disagreements. Identify consensus, disagreements, complementary perspectives, unsupported claims, unresolved hypotheses, evidence needed, and learner reflection questions.

Return keys: `consensus`, `disagreements`, `complementary_perspectives`, `unsupported_claims`, `unresolved_hypotheses`, `evidence_needed`, `reflection_questions`. Values are arrays of strings.
